# organizador-de-arquivos

## Explicando o que é:
Esse projeto é simples, estou treinando um pouco de Python e automação de processos então decidi criar esse organizador de arquivos na pasta downloads do meu pc, em que todos os arquivos com extensão: .pdf, .jpeg, .img, .exe, .docx serão listados, e armazenados em pastas separadas criadas pelo próprio Python. Com isso mantem a organização e sempre que precisar organizar os downloads, basta executar o código.

### Em atualizações futuras irei colocar coisas como: Sempre que iniciar o Windows a automação rodar automaticamente.
